# HiveCompass

HiveCompass enables real-time, big-data processing with auto-scaling capabilities, leveraging a robust manager-engine architecture.

HiveCompass is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/HiveCompass.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

HiveCompass is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
